# Number Pattern Generator (C Language)

A interactive command-line application built in C that generates various numeric and star patterns based on user-defined sizes. Built for the TechNova C Programming Internship.

## 🚀 Features
* **Multiple Pattern Options:** Right-angled star triangle, symmetric number pyramid, inverted numeric triangle, and Floyd's triangle.
* **Custom Sizing:** Accepts dynamic row size input from the user.
* **Nested Loops:** Clean implementation of inner/outer loop architectures.
* **Continuous Loop:** Menu interface allows multiple runs without restarting the program.

## 🛠️ Compilation & Execution
```bash
gcc pattern_generator.c -o pattern_generator
./pattern_generator
